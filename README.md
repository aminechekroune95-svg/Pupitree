# Pupitre

Application web d'entraînement au piano à l'écoute (micro du téléphone) : réglage sur un piano non accordé, lecture de notes, accords, tempo, nuances, vocabulaire musical, et la *Valse de l'adieu* de Chopin (op. posth. 69 n° 1) passage par passage.

Ouvrir : https://aminechekroune95-svg.github.io/Pupitree/
